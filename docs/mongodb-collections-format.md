# MongoDB Collection Formats

This file shows the data shape used by this service.

## Database

- Name: `erlc_gateway`

---

## Collection: `webhooks`

Stores created webhooks from `POST /webhook/create`.

### Fields

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `_id` | ObjectId | Yes (MongoDB) | Auto-generated by MongoDB |
| `webhookId` | string | Yes | Generated with `crypto.randomBytes(12).toString("base64url")`; unique |
| `robloxID` | string | Yes | Roblox identifier submitted by client |
| `username` | string | Yes | Username submitted by client |
| `webhookURL` | string | Conditional | Required for `easy`/`proxy`, optional for `poll` |
| `mode` | string | Yes | One of `poll`, `easy`, `proxy` |
| `createdAt` | Date | Yes | Server timestamp when created |

### Example Document

```json
{
  "_id": { "$oid": "65f1f1f1f1f1f1f1f1f1f1f1" },
  "webhookId": "r4vP3v8Z2hLwq0oN",
  "robloxID": "1234567890",
  "username": "example_user",
  "mode": "poll",
  "createdAt": { "$date": "2026-03-24T12:34:56.000Z" }
}
```

### Index

```js
{ webhookId: 1 } // unique
```

## Collection: `webhookEvents`

Stores poll-mode events until they are fetched by `GET /webhook/:id/events`.

### Fields

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `_id` | ObjectId | Yes (MongoDB) | Auto-generated by MongoDB |
| `webhookId` | string | Yes | Links event to a webhook in `webhooks` |
| `event` | string | Yes | Event name from ERLC payload (`events[i].event`) |
| `userId` | string | Yes | Copied from ERLC payload (`events[i].origin`) |
| `timestamp` | string or number | Yes | Original event timestamp from ERLC payload |
| `server` | object | Optional | Copied from payload `server` if present |
| `createdAt` | Date | Yes | Inserted by this service for queue/TTL control |
| `...eventDataFields` | mixed | Optional | Flattened keys from `events[i].data` |

### Example Document

```json
{
  "_id": { "$oid": "65f1f2f2f2f2f2f2f2f2f2f2" },
  "webhookId": "r4vP3v8Z2hLwq0oN",
  "event": "PlayerJoined",
  "userId": "9988776655",
  "timestamp": 1711281000,
  "player": "OfficerJane",
  "department": "LAPD",
  "server": {
    "id": "server-1",
    "name": "Main RP"
  },
  "createdAt": { "$date": "2026-03-24T12:35:03.000Z" }
}
```

### Index

```js
{ createdAt: 1 } // TTL: expireAfterSeconds = 600
```

### Queue Behavior

- New poll events are inserted into `webhookEvents`.
- Service keeps only the newest 50 events per webhook.
- `GET /webhook/:id/events` returns events and then deletes returned documents.
- TTL index removes stale items after 10 minutes.
